# ミニブラウザヒーロー

GitHub Pagesで動く、HTML/CSS/JavaScriptだけのブラウザゲームです。

## 実装済み

- ヒーローは右側、敵は左側から出現
- 自動戦闘
- レベルアップでステータス上昇
- 宝箱ドロップ演出
- SE、音量調整、ミュート
- ステージ進行（1-1、1-2...）
- クリア済みステージ選択
- ランダム能力付き装備ドロップ
- 武器・防具・指輪の装備システム
- localStorage自動セーブ

## 公開方法

1. このフォルダの中身をGitHubリポジトリへアップロード
2. Settings → Pages
3. Sourceを `Deploy from a branch`
4. Branchを `main` / `/root` にして保存
