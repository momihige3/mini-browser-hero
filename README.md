# ミニブラウザヒーロー

GitHub Pagesでそのまま動くブラウザ放置ハクスラです。

## 更新方法

1. ZIPを展開
2. `index.html`, `style.css`, `game.js`, `README.md` をGitHubリポジトリ直下に上書き
3. Commit
4. Push
