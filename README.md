# ミニブラウザヒーロー v28

GitHub Pagesで動くブラウザ放置ハクスラです。

## 更新内容
- 主人公名を「騎士」に変更
- AUTOボタンを削除して常時自動戦闘に変更
- バトル下部のスキル選択を削除
- 通常攻撃は斬撃固定、武器に付いたスキルがランダムで追加発動
- 装備ボタンで右側UIをバトル画面上に開閉表示
- 音とBGMを追加
- Gold表示を削除
- 死線の剣舞中は名前欄に残り時間を表示
- 現在Lv経験値、次Lv必要経験値、直近獲得経験値を表示

## 使い方
`index.html` を開くだけで遊べます。
GitHub Pagesではこの一式をリポジトリ直下に置いてください。
