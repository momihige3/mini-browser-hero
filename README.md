# ミニブラウザヒーロー v16

GitHub Pagesで動くブラウザ放置ハクスラです。

## v16変更点

- 黒髪剣士のリアル寄りSVGグラフィックを追加
- 武器にランダムスキルを追加
  - 連続攻撃
  - 大攻撃
  - 炎斬り
  - 雷撃
- スキル発動時の斬撃エフェクトを追加
- 斬撃を敵の右上から左下へ切る動きに変更
- 被ダメージ無効表示を `GUARD` に変更
- 一括売却をブラウザ確認モーダルではなくゲーム内UI化
- 一括売却UI表示中もバトル継続
- 右側の設定・冒険ボタン見切れを修正
- ログをマウスホイールで過去ログ確認できるよう変更
- ダメージ数値をHPバーに重なりにくい位置へ調整

## 更新方法

ZIPを展開して、中身の `index.html` / `style.css` / `game.js` / `assets` をGitHubリポジトリへ上書きしてください。
