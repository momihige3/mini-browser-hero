# ミニブラウザヒーロー

GitHub Pagesで動くブラウザ放置ハクスラゲームです。

## v5 内容

- 赤黒ゴールドのドット風UI
- 右側ヒーロー、左側敵の自動戦闘
- 敵撃破時の点滅消滅
- 次の敵が画面外から歩いて登場
- 被ダメージ時の白フラッシュ
- 短い斜め斬撃エフェクト
- SE、音量、ミュート
- ステージ進行とステージ選択
- 宝箱ドロップ演出
- ランダム能力付き装備ドロップ
- 倉庫グリッド、装備比較、装備・売却
- localStorage自動セーブ

## GitHub Pages

リポジトリ直下にこの中身を置いて、Settings → Pages → main / root を選ぶと公開できます。
