# ミニブラウザヒーロー

GitHub Pagesでそのまま動く、横スクロール風のブラウザ放置ゲームです。

## 実装済み

- 敵が右から出現する横スクロール風の自動戦闘
- 敵撃破でGoldとEXP獲得
- レベルアップで攻撃力、防御力、最大HP、攻撃速度が上昇
- 10Waveごとにボス出現
- 通常敵は12%、ボスは100%で宝箱ドロップ
- 宝箱ドロップ演出
- 宝箱を開けてGoldとEXPを獲得
- 武器、防具、指輪の強化
- localStorageによる自動セーブ

## GitHub Pagesで公開する方法

1. このフォルダの中身をGitHubリポジトリにアップロードします。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Deploy from a branch` を選びます。
4. `main` / `/root` を選んで保存します。
5. 表示されたURLを開くと遊べます。
