# ミニブラウザヒーロー v24 高画質カード版

GitHub Pagesでそのまま動くブラウザゲーム版。

## 追加内容
- 高画質背景・主人公カード・敵カード8種を実際に適用
- 雑魚：スライム、ゴブリン、リザード、火の精霊
- ボス：スライムキング6%、オーク3%、ドラゴン0.5%、火の精霊王0.5%
- ステージ制撤廃、ランダム敵抽選
- 属性システム
  - ドラゴンは火属性半減
  - 火の精霊、火の精霊王は火属性吸収
  - ドラゴン/火の精霊/火の精霊王は火属性攻撃を使用
- 防具に火軽減・雷軽減ステータス
- LEVEL UP演出
- HP0でDOWN、5秒後にHP50%で復活
- HP0時10%で「死線の剣舞」発動
  - HP1で耐える
  - 10秒間無敵
  - 連撃のみ
  - 10秒かけてHP50%まで回復
  - クールダウンなし
- 生成済みエフェクト画像から切り抜いた素材を使用

## 使い方
`index.html` を開くだけ。
GitHub Pagesでは中身をそのままアップロード。
